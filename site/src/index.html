BFO-Aligned ValueNet

An ontology of human values as realizable entities that inhere in an agent and are realized when that agent appraises, chooses, feels, or acts.

Why I built this

A statement from the author, Aaron Damiano.

More and more of the decisions that shape people's lives are made, or shaped, by AI systems: who gets hired, who gets flagged, what we read, what we are told is true. Many of those systems can't reliably show why they said what they said. Human dignity depends on agency: on being the one who decides, and on being able to see and challenge the reasons behind decisions made about you. If we hand moral judgment to systems we can't inspect, we surrender that agency, even when the answers sound good.

So the problem I am working on is whether we can build systems whose moral reasoning is transparent and accountable by design. Not a machine that decides what is right, but one that shows its work, so that a human stays answerable for the decision. That work is Integral Ethics, and it is part of a larger body of work, Ethical Computation.

Its division of labour is propose, constrain, decide. A language model proposes: it reads messy human text and suggests what might be at stake. An ontology constrains: it forces those suggestions into explicit, checkable claims. And a person decides. Integral Ethics is being designed so that it never makes the moral decision, and there is no finished system yet. What exists so far is the design, a test instrument, and this ontology.

BFO-Aligned ValueNet is the value foundation for that work. To make moral reasoning inspectable you first need a way to write values down that a machine can work with and a person can argue with. ValueNet is one, and it is not mine: it was created by Stefano De Giorgis, Aldo Gangemi and Rossana Damiano. What I built is a refactoring of it onto a different foundation, the Basic Formal Ontology.

That foundation buys one move. A value is not a floating abstraction like fairness in general. It is a disposition that a real person bears, and what goes against it is a process: an event in the world. Values belong to someone.

So a moral reading of a text stops being one vague judgment and becomes separate claims: which words, which value, whose value it is, and whether it was realized or violated. Each can be disputed on its own terms. You can agree about the value and dispute who bears it. Not precision for its own sake: precision so that disagreement has somewhere to land.

We shouldn't be asking whether AI can be moral. We should be asking whether its moral reasoning can be audited by the people it affects.

The core pattern

The model keeps apart things that a list of value labels runs together: what somebody holds, what happens when they act on it, and what happens when it is gone against.

Value disposition
What somebody holds: a standing tendency of an agent, grounded in how that agent is. A value borne because of a position an agent occupies is a value role instead.
Value realization process
What happens when a value is acted on. It realizes the disposition without being it: the disposition was there before and is there afterwards.
Value violation process
What happens when a value is gone against. An act can contravene a value its own agent bears, so the model can say so without claiming the agent lacks the value.

The models page draws this pattern and the others the suite uses, each with a written description.

Why BFO alignment

BFO is the Basic Formal Ontology, an upper ontology: a small set of very general categories that more specific ontologies are built beneath. CCO is the Common Core Ontologies, which this suite reuses for agents and for the information entities that record textual evidence.

A bearer
A value disposition inheres in an agent. Asking whose value it is has an answer in the model rather than in a naming convention.
A realization
Holding a value and acting on it are different entities. The disposition persists; the realization process occurs. So does its counterpart, the violation process.
Interoperability by construction
Every class descends from a BFO or CCO term, so ValueNet composes with other BFO-aligned ontologies rather than needing a bespoke bridge to each one.

What is measured

Ontology changes here are measured rather than asserted. The repository records a semantic fingerprint of the whole corpus that reproduces from any checkout, an experiment showing why earlier digests did not, and a triple-by-triple record of every source-data repair made since.

The suite has also been through a formal ontology review. The review, the response to it, the decisions that followed and the reviewer's sign-offs are all in the repository, and the documentation page links to each, beside the evidence records and the register of what is still open.

None of this is a claim that the ontology is correct. It shows that the measurements reproduce and that the changes are accounted for.
