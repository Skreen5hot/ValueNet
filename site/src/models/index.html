Models

Three patterns that say how this suite uses BFO. Every class and property drawn here is declared by the module named beside it, and a test checks that before the site is published.

Each diagram is followed by a written description giving the same nodes and the same relations, so nothing is only available as a picture. Class names link into the explorer.

1. The realization pattern

A value is not a belief, a label, or a concept. In this suite a value is a realizable entity that an agent bears and that processes realize. That single commitment is what makes the rest of the vocabulary BFO-shaped rather than BFO-flavoured.

The split below is the consequence. A value held by an agent is a disposition: it is grounded in how that agent is. A value borne because of a position an agent occupies is a role: it is grounded in a social context and would end if the context did. Both are realizable, so both are realized in processes rather than being processes themselves.

Description of diagram 1

  • Value-related realizable entity (valuenet-core) is a kind of BFO BFO_0000017 realizable entity, which is upstream BFO and not authored here.
  • Value disposition is a kind of value-related realizable entity and also a kind of BFO BFO_0000016 disposition.
  • Value role is a kind of value-related realizable entity and also a kind of BFO BFO_0000023 role.
  • An agent (CCO ont00001017, upstream) is bearer of (BFO_0000196) a value disposition.
  • Value realization process is a kind of BFO BFO_0000015 process, and realizes a value role or a value disposition.

2. Foundations and the processes that contravene them

The moral-foundations module pairs each foundation with the process that runs against it. The pairing is asserted in the ontology as a restriction on the process: a harm process contravenes some care disposition. It is not inferred from the names, and the six pairs below are read out of the file rather than typed here.

Both halves stay inside the realization pattern above. A foundation is a moral value disposition, so it is realizable and borne; a contravening process is a value violation process, so it is a process. Nothing is both.

Description of diagram 2

Six pairs, drawn left to right as process contravenes disposition. Every disposition named here is a moral value disposition; every process is a value violation process.

  • Harm process contravenes care disposition.
  • Cheating process contravenes fairness disposition.
  • Betrayal process contravenes loyalty disposition.
  • Subversion process contravenes authority disposition.
  • Degradation process contravenes sanctity disposition.
  • Oppression process contravenes liberty disposition.

3. From original ValueNet to a BFO-aligned value

This suite does not replace the original ValueNet. It provides a BFO-aligned vocabulary and records, as annotations, how the two line up. The path below is how a piece of text becomes evidence about a value without any of those steps being collapsed into the others.

The mapping annotations are deliberately weak. They say a term historically corresponds to, or conceptually matches, another term. They are not equivalences and no reasoner is asked to treat them as such: asserting owl:equivalentClass across two vocabularies with different commitments would import the other vocabulary's consequences wholesale.

Description of diagram 3

Two groups, drawn one above the other because they are separate claims and not one chain.

  • Mapping. The original ValueNet term HaidtValues#Care (upstream) historicallyCorrespondsTo care disposition. This is one of 67 such assertions, drawn here because it is the shortest complete example. The arrow is dashed because a mapping is an annotation and carries no logical consequence.
  • Evidence. A text span isTextSpanOf a textual representation.
  • A text span selector selectsTextSpan a text span, and records its start and end offsets.
  • A value evidence annotation hasEvidenceSource a text span and hasSelector a text span selector.

Two further steps are part of this path and are not drawn, so the figure stays readable. Both are asserted in valuenet-core: an evidence source isEvidenceFor a BFO BFO_0000015 process — in this suite a value realization process — and a text span evokesFrame the frame a lexical trigger names. Trigger data reaches the path through vcvf:triggers, an upstream property whose annotation semantics are supplied by the trigger-semantics module.
